### 7.2 Lead Scoring Algorithm (Automated on Create + Enrichment)
```python
def score_lead_v2(lead: dict) -> tuple[int, str]:
    """Returns (score 0-100, classification)"""
    score = 0
    
    # Firmographics (max 30)
    if lead.get('estimated_size') in ('51-200', '201-500', '500+'): score += 15
    elif lead.get('estimated_size') == '11-50': score += 10
    if lead.get('industry') in ('healthcare', 'education', 'shopping', 'logistics', 'manufacturing'): score += 15
    elif lead.get('industry') in ('restaurant', 'retail', 'property', 'hospitality'): score += 10
    if lead.get('site_count', 1) > 1: score += 10
    
    # Contact Quality (max 25)
    if lead.get('job_title') and any(t in lead['job_title'].lower() for t in ['facilities', 'operations', 'shea', 'property', 'director', 'owner', 'manager']): score += 15
    if lead.get('whatsapp'): score += 5
    if lead.get('phone') and len(lead['phone'].replace(' ', '').replace('-', '')) >= 10: score += 5
    
    # Intent Signals (max 30)
    if lead.get('source') in ('referral', 'website_directory', 'industry_directory', 'property_directory', 'healthcare_directory', 'education_directory'): score += 15
    if lead.get('interest') in ('fire-safety-assessment', 'site-inspection', 'compliance'): score += 15
    if lead.get('trigger') in ('coc_expiry', 'insurance_renewal', 'inspector_visit', 'new_premises'): score += 20
    
    # Recency (max 15)
    days_since_created = (now - lead['created_at']).days
    if days_since_created <= 7: score += 15
    elif days_since_created <= 30: score += 10
    elif days_since_created <= 90: score += 5
    
    # Classification
    if score >= 80: classification = 'HIGH'
    elif score >= 60: classification = 'MEDIUM'
    elif score >= 40: classification = 'LOW'
    else: classification = 'NURTURE'
    
    return min(score, 100), classification
```

## 8. QUALIFICATION PROCESS (Sales Handoff)

### 8.1 BANT Framework (Mandatory Before Appointment)
| Criteria | Questions | Capture Location |
|----------|-----------|------------------|
| **Budget** | "What's your annual fire compliance budget?" / "Is R15k-30k for annual compliance within budget?" | `leads.opportunity_value_cents`, `leads.notes` |
| **Authority** | "Are you the decision-maker for fire safety?" / "Who else needs to sign off?" | `leads.job_title`, `leads.notes` |
| **Need** | "When does your COC expire?" / "Any failed inspections?" / "How many extinguishers on site?" | `leads.fire_safety_relevance`, `leads.notes`, `leads.estimated_size` |
| **Timeline** | "When do you need this done?" / "Any urgent compliance deadlines?" | `leads.next_action_date`, `leads.notes` |

### 8.2 Qualification Call Script (5 Minutes)
1. **Confirm Identity** — "Hi [Name], calling from SmartBiz Fire about your fire compliance..."
2. **Pain Discovery** — "How are you currently managing extinguisher servicing and COCs?"
3. **BANT** — Budget, Authority, Need, Timeline (as above)
4. **Value Bridge** — "We handle the full lifecycle digitally — you get a portal, automated reminders, valid COCs."
5. **CTA** — "Can I book a free 45-min assessment this week? Tuesday 10am or Thursday 2pm?"
6. **Next Step** — Book in calendar → Create `booking` → Update `lead_status='APPOINTMENT'`

### 8.3 Disqualification Criteria (Move to NURTURE/LOST)
- No budget (<R10k annually)
- No authority (gatekeeper only, no access to DM)
- No need (recently serviced, valid COC >6 months)
- No timeline (not planning action in 90 days)
- Wrong geography (outside Gauteng service area)
- Hostile / Opt-out
